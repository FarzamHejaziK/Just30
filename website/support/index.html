A LITTLE HELP.

Support for JustThirty

JustThirty gives your selected apps and websites one combined 30-minute allowance per day on each device. The Mac version is available as a free early release. The iPhone App Store release is still in preparation.

Start, pause, resume

Start access when you want to open your saved apps and websites. The timer continues while you switch away, lock the device, or close the app. Pause access to restore blocking and keep your unused time. Resume later the same day. The allowance resets at midnight in the original allowance time zone; minutes do not carry over.

Review additions carefully

Saved entries cannot be removed in the app. Website suggestions can include more than one related domain: review the displayed domains before confirming. A pasted URL adds domains rather than a single page. Selecting an entire category can block many apps and websites.

iPhone: blocking needs attention

  • Open JustThirty and enable Screen Time access when prompted.
  • Check that your selection is saved and timed access is paused or exhausted.
  • Website coverage depends on Apple’s filtering and the browser. Adding typed website restrictions can disable Safari Private Browsing.
  • If access stays open after the timer ends, reopen JustThirty to restore its saved restrictions and report the behavior.

Install JustThirty for Mac

Requires macOS 14 or later. The same download runs on Apple silicon and Intel Macs.

  1. Download JustThirty for Mac, then double-click the ZIP in Downloads to unzip it.
  2. Move JustThirty into Applications and double-click it to open.
  3. Choose “Set up background blocking” and approve the Mac’s administrator prompt.

This free early release is developer-signed and Apple-notarized. Read the release notes and verify the download.

Updating an existing installation

Quit the current app first. Replace the existing app in its current location; if it is still named OneWay.app, keep that filename. Avoid keeping both versions installed. Keep your existing background-service data to preserve your saved list and timer. Open the updated app, run background setup if prompted, and confirm that blocking is healthy.

Mac: finish background setup

Move the app into Applications, open it, and use Set up background blocking. Approve JustThirty in System Settings → General → Login Items & Extensions if requested. Your Mac may show the developer’s name in that approval.

Save your browser work before pausing or ending access. The service closes supported browsers to clear connections, which can interrupt unsaved work. Existing browser connections can continue briefly after adding a domain; fully quit and reopen the browser. Proxies, alternate DNS behavior, and domains not explicitly included in the saved list can bypass host-based rules. An administrator retains control of the Mac.

Report an issue

Open a support issue on GitHub ↗

Include the app version, operating-system version, device model, and steps to reproduce. GitHub issues are public: omit private websites, personal activity, signing information, and credentials. Use example.com when describing a domain problem.
